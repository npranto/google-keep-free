# 01.02.03: Drizzle client over Neon with select 1

**Status:** ready-for-agent
**Parent:** 01.02-env-validation-and-db-connection.md
**Blocked by:** 01.02.01, 01.02.02
**Unblocks:** 01.02.04

## Purpose

Expose a working Drizzle DB client that reaches Neon.

## Scope

Install `drizzle-orm` and `@neondatabase/serverless`. `lib/db/index.ts` (client reading
the URL only from `lib/env.ts`), empty `lib/db/schema.ts` placeholder, and a `select 1`
check run against Neon (script or test, not a route).

## Out of scope

Tables, migrations, Drizzle Kit config, any `/api/*` route.

## Acceptance criteria

- [ ] A trivial `select 1` through the DB client succeeds against the Neon project from
      01.02.01.
- [ ] The client reads config only through `lib/env.ts`.
- [ ] `build` and `lint` still pass.

## Demo / verification

Run the `select 1` check and see it succeed against Neon.

## Review budget / risk

About 15 minutes. Risk: driver choice (HTTP vs WebSocket) for Vercel serverless per
ADR 0001.
