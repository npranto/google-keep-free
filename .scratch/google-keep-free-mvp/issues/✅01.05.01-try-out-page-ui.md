# 01.05.01: Try-out page UI (static, dummy content)

**Status:** closed
**Lane:** Quick
**Parent:** 01.05-vercel-deploy.md
**Blocked by:** None (needs no credentials, integrations or database)
**Unblocks:** None

## Purpose

Put a public page at `/try-out`. It will become a landing page later. For now it holds
placeholder content shaped like one.

## Scope

A new public route `/try-out` (`app/try-out/page.tsx`) rendering a static server
component with hard-coded dummy copy, laid out as a small landing skeleton: a full-width
hero, three benefit cards and a closing band. The hero has one call to action that links
to `/sign-up`. The page exports its own `metadata`: a page title, and `noindex` for as
long as it holds dummy copy. It sits outside the `(app)` route group, so it needs no
sign-in, the same as `/about`, `/faq` and `/stuff`. Tailwind and the existing `Button`
only, no new dependencies.

## Out of scope

Real content or copy, real metadata (description, Open Graph), a site-wide `robots.txt`
or sitemap, images or asset uploads, client state or event handlers, forms, data
fetching, auth or Clerk changes, database, `/api/*` handlers, navigation or header/footer
changes, and linking the page from anywhere else. The existing `/about`, `/faq` and
`/stuff` pages and the shared components are not changed.

## Acceptance criteria

- [x] `/try-out` answers 200 for a signed-out visitor and shows a hero heading, three
      benefit cards and a closing band, all placeholder copy.
- [x] All content is hard-coded dummy data; no data fetching, no `"use client"` and no
      event handlers.
- [x] Layout holds at 390, 820 and 1440 wide with no horizontal scroll, the benefit cards
      reflow from one to three columns, and text stays readable.
- [x] The page is its own route; no other existing route, layout or component changes
      in behavior, content or markup.
- [x] No new dependencies, no env vars, no `/api/*` handlers, no auth or DB dependencies.
- [x] Lint, typecheck, tests and build pass.
- [x] The page has its own tab title and sends `noindex`.
- [x] The hero has one call to action, and it goes to `/sign-up`.

## Demo / verification

Run the dev server, open `/try-out` signed out, and check the page at mobile, tablet and
desktop widths for spacing, contrast and overflow. Follow the call to action to
`/sign-up`. Check the tab title and the `robots` meta tag in the page source.

## Review budget / risk

Tiny, about 5 minutes. Low risk since it is isolated to one new route file.

## Decisions

All three were made by the user during the ticket-level grill in scope-check (decisions 1
to 3 on Sun 11 and Mon 12 Oct 2026).

### 1. What is `/try-out` for?

**Pick:** `/try-out` will become a landing or marketing page later. For now it holds
dummy content shaped like one: a headline and benefits.

**Rejected:**
- A no-sign-in demo of the app, later: not what the page is for.
- A scratch page for trying UI ideas: not what the page is for.
- No purpose yet, smallest possible page: the page has a known destination, so the
  placeholder follows its shape.

**Evidence:** none recorded.
**Principle:** Purpose before shape. Placeholder copy still makes a promise about what
the page will become, so the purpose is settled before the layout.
**Undo:** trivial. The copy lives in `app/try-out/page.tsx` and is replaced wholesale.
**Decided by:** user.

### 2. Should the dummy page be indexed, and does it get its own tab title?

**Pick:** the page exports its own `metadata`: a page title, and `noindex` for as long as
it holds dummy copy. The agent recommended no page metadata; the user chose title plus
`noindex`.

**Rejected:**
- No page metadata, same as `/about`, `/faq` and `/stuff`: leaves dummy copy indexable.
- Tab title only: same, and adds a placeholder title to rewrite later.
- A site-wide `robots.txt` or sitemap: no acceptance criterion needs one, and it changes
  behavior for every route.

**Known trap:** `noindex` must be removed when the real landing copy ships, or the landing
page stays out of search with no error anywhere. Guarded by a comment beside the
`metadata` export in `app/try-out/page.tsx` and by ticket 01.05.02.

**Evidence:**
- *Measured:* `gfk.lol/robots.txt` and `gfk.lol/sitemap.xml` answer 404, nothing links to
  `/try-out`, and only `app/layout.tsx` exports `metadata` today.
- *Inferred:* an unlinked page with no sitemap is rarely crawled.

**Principle:** Prefer the failure that heals itself. The user accepted the stickier
failure (a forgotten `noindex`) in exchange for keeping dummy copy out of search.
**Undo:** trivial. Delete the `robots` line from the `metadata` export.
**Decided by:** user.

### 3. What does the dummy landing content look like?

**Pick:** a small landing skeleton in one file, `app/try-out/page.tsx`: a full-width
hero, three benefit cards that reflow from one to three columns, and a closing band. The
hero has one call to action, a real link to `/sign-up`. Neutral theme tokens only. The
agent recommended the skeleton with no buttons or links; the user added the call to
action.

**Rejected:**
- The same pitch copy inside the `/about` card shell: matches two sibling pages, but a
  narrow card is not a landing layout, so the layout would be rebuilt later.
- A headline and one line: says nothing about where the page is going.
- A long colorful page like `/stuff` (704 lines): the user passed on a bigger page.
- A shared page-shell component for the public pages: edits shipped pages, breaks the
  "nothing else changes" criterion, and moves the lane to Standard.
- Inert buttons: the `/stuff` review flagged three of them.

**Accepted risk:** the call to action sends real visitors into sign-up from placeholder
benefit copy. Kept small by `noindex` (decision 2), by nothing linking to `/try-out`, and
by copy that says plainly it is placeholder text.

**Evidence:**
- *Measured:* `docs/design/` has no landing page design. `Button` in
  `components/ui/button.tsx` supports `asChild`, so it wraps a `next/link` `Link` with no
  change to the component.
- *Guess:* the real landing page keeps the hero, benefits and closing sections.

**Principle:** A placeholder should match the shape, not the detail: get the structure
right now, keep the filling minimal and honest about being fake.
**Undo:** trivial. One file, replaced wholesale.
**Decided by:** user.
