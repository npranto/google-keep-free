# 01.04: Static app shell and Notes empty state

**Status:** ready-for-agent
**Parent:** 01-application-foundation.md
**Blocked by:** 01.03
**Unblocks:** 01.05

## Purpose

Show the shell an Owner sees on first login.

## Scope

`AppShell`, `TopBar` (search input renders but does nothing), `Sidebar` (Notes, Archive,
Trash only), shared `components/notes/EmptyState.tsx`, wired into `app/(app)/page.tsx`
with "Notes you add appear here".

## Out of scope

Labels nav, search wiring, composer, responsive behavior, separate pages per view.

## Acceptance criteria

- [ ] Signed in, `/` shows top bar, sidebar and the empty state "Notes you add appear here".
- [ ] Sidebar highlights "Notes" as selected; Archive/Trash are present but inert.
- [ ] Single route `/`; no `/api/*` handlers.

## Demo / verification

Sign in and inspect the shell visually, checking pixel-level alignment and spacing.

## Review budget / risk

About 15 minutes. Hot files for later tickets, so get component boundaries right.
