# 01.05.02: Try-out page: real landing copy

**Status:** open
**Lane:** Standard (proposed: the copy and the page's final shape are not decided yet)
**Parent:** 01.05-vercel-deploy.md
**Blocked by:** 01.05.01
**Unblocks:** None

## Purpose

Turn the placeholder at `/try-out` into the real landing page, and let search engines
index it.

## Scope

Replace the dummy copy in `app/try-out/page.tsx` with real landing copy, and replace the
placeholder `metadata` with real values. Remove `robots: { index: false }` and the
comment above it, so the page can be indexed.

Not decided yet, to settle at scope-check: the copy itself, whether the three-section
skeleton stays, and whether anything links to the page.

## Out of scope

To be set when the copy is decided.

## Acceptance criteria

- [ ] No placeholder copy is left on `/try-out`, and the "Placeholder page" label is gone.
- [ ] The page no longer sends `noindex`: the served HTML has no `robots` meta tag that
      blocks indexing.
- [ ] The page has a real title and description.
- [ ] Every benefit the page names is a feature that works in production on the day it
      ships.
- [ ] The call to action leads to a sign-up a visitor can finish. Check the state of
      Clerk email codes on production first (`docs/architecture/codebase-map.md`,
      "Documentation gaps").
