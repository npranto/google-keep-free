# 01.02.02: Zod-validated env module

**Status:** ready-for-agent
**Parent:** 01.02-env-validation-and-db-connection.md
**Blocked by:** None (01.01 is done; needs no real credentials)
**Unblocks:** 01.02.03 (parallel with 01.02.01)

## Purpose

Fail fast at startup with a clear error when `DATABASE_URL` is missing or invalid.

## Scope

`lib/env.ts` (Zod, `DATABASE_URL` only, single exported schema so 01.03 can add Clerk
vars additively), `.env.example` documenting each variable, tests for missing, invalid
and valid values, `zod` dependency.

## Out of scope

DB client, Drizzle, Clerk env vars.

## Acceptance criteria

- [ ] Missing or invalid `DATABASE_URL` fails startup with a clear error naming the
      variable.
- [ ] A well-formed `DATABASE_URL` loads without error.
- [ ] `.env.example` documents every variable in `lib/env.ts`.

## Demo / verification

Unset `DATABASE_URL` and observe the error; set a well-formed URL and observe it load.

## Review budget / risk

Small. Hotspot: 01.03 extends `lib/env.ts`, so keep its shape additive.
