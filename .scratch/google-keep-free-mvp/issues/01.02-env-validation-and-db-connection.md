# 01.02: Validated env and Neon/Drizzle connection

**Status:** ready-for-agent
**Parent:** 01-application-foundation.md
**Blocked by:** 01.01
**Unblocks:** 01.03

## Purpose

Fail fast on bad config and expose a working DB client.

## Scope

`lib/env.ts` (Zod-validated, initially `DATABASE_URL`), `.env.example`,
`lib/db/index.ts` (Drizzle + Neon), empty `lib/db/schema.ts` placeholder, drizzle config.

## Out of scope

Any tables, Clerk env vars.

## Acceptance criteria

- [ ] Missing or invalid `DATABASE_URL` fails startup with a clear error.
- [ ] A trivial `select 1` through the DB client succeeds against Neon.
- [ ] `.env.example` documents every variable in `lib/env.ts`.

## Demo / verification

Unset `DATABASE_URL` and observe the error; set it and run a `select 1`.

## Review budget / risk

Small. `lib/env.ts` is extended by 01.03, so keep its shape additive.
