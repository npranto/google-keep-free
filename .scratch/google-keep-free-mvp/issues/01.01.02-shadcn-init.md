# 01.01.02: shadcn/ui init with one primitive

**Status:** ready-for-agent
**Parent:** 01.01-nextjs-scaffold-tailwind-shadcn.md
**Blocked by:** 01.01.01
**Unblocks:** 01.02 (once 01.01 is complete)

## Purpose

Establish the shadcn/ui component baseline so later tickets can add primitives.

## Scope

shadcn init (`components.json`, `lib/utils.ts`, theme tokens in global CSS,
`components/ui/*` baseline), one primitive (e.g. Button) rendered on the placeholder page.

## Out of scope

Any other primitives, shell components, env, DB, auth.

## Acceptance criteria

- [ ] shadcn is initialised and one primitive renders correctly styled on `/`.
- [ ] `dev`, `build` and `lint` still pass.

## Demo / verification

Run `dev`, open `/`, see the styled primitive; run `build` and `lint`.

## Review budget / risk

Small, mostly generated. Risk: theme token changes to global CSS touch a shared file.
