# 01.02.01: Neon account, project and DATABASE_URL (human step)

**Status:** ready-for-human
**Parent:** 01.02-env-validation-and-db-connection.md
**Blocked by:** None (can start immediately)
**Unblocks:** 01.02.03

## Purpose

Get a working Neon Postgres and its connection string into a local, gitignored `.env.local`.

## Scope

A step-by-step guide (runnable with the `mattpocock-skills:wizard` skill, or by hand) for:

- Signing up for Neon (assume no account exists).
- Creating a project and database, region close to the intended Vercel region.
- Copying the pooled connection string (ADR 0001: pooled/serverless driver from Vercel).
- Saving it as `DATABASE_URL` in `.env.local`.
- Confirming `.env*` is gitignored (except `.env.example`).

## Out of scope

Any code, Vercel env vars (01.05), Neon branches per Preview Deployment, Clerk account
(handled with 01.03).

## Acceptance criteria

- [ ] A Neon project exists and its pooled connection string is in `.env.local` as
      `DATABASE_URL`.
- [ ] `psql "$DATABASE_URL" -c 'select 1'` (or the Neon SQL editor) returns `1`.
- [ ] `git status` shows `.env.local` is not tracked.

## Demo / verification

Run the `select 1` above against the string you saved.

## Review budget / risk

Under 15 minutes. Risk: copying the direct string instead of the pooled one, or dropping
`sslmode=require`.
