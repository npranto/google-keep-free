## Purpose

Let the server create a Note for the signed-in Owner and list that Owner's Active Notes,
with the ownership and length rules proven on the real database before any UI exists.

## Out of scope

Any UI, `updateNote`, autosave, the other view queries, rate limiting.

## Acceptance criteria

- [x] `createNote` with content inserts one Note as `active`, owned by the caller, and
      returns its `id` and `version`: 02.02.02
- [x] `createNote` with empty title and empty body (including whitespace only) inserts no
      row and returns a `validation` error: 02.02.01, 02.02.02
- [x] A title over 300 or a body over 20000 characters is rejected before any database
      call, and exactly 300 and 20000 are accepted: 02.02.01, 02.02.02
- [ ] `getActiveNotes()` returns only the caller's Active Notes. A second Owner's session
      never sees them: 02.02.03
- [x] A client-supplied `ownerId` in the input is ignored: 02.02.01, 02.02.02
