# 01.02.03.02: Stuff page UI (static, gibberish content)

**Status:** in-progress
**Parent:** 01.02.03-drizzle-neon-client-select-1.md
**Blocked by:** None (needs no credentials, integrations or database)
**Unblocks:** None

## Purpose

Show what a visitor sees on a long, colorful, highly scrollable page full of
placeholder content, as a standalone route.

## Scope

A new route `/stuff` (`app/stuff/page.tsx`) rendering a static server component with
about 16 sections of gibberish copy. Each section has its own color theme and a
different layout (for example gradient hero, stat tiles, card grid, quote band,
timeline, tag cloud), so the page reads as unique and colorful. Tailwind only, no new
dependencies, no client JS. Dummy copy only.

## Out of scope

Real content or copy, images or asset uploads, client interactivity, CMS or data
fetching, search or filtering, forms, auth or Clerk, database, `/api/*` handlers,
navigation or header/footer changes, and linking the page from anywhere else. The
existing `/about` and `/faq` pages are not changed.
