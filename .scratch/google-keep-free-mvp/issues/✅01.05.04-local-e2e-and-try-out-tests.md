# 01.05.04: Local E2E works, and /try-out and the sign-in redirect are covered

**Status:** closed
**Lane:** Standard (shared test config used by every spec, and a new place that sends a secret header)
**Parent:** 01.05-vercel-deploy.md
**Blocked by:** 01.05.03
**Unblocks:** 01.05.05

## Purpose

`npm run e2e` cannot run its one test locally, and `/try-out` shipped with no test.
Make the suite runnable from a clean checkout, and cover what shipped untested. Items 3
and 4 of 7.

## Scope

- `playwright.config.ts` loads `.env.local`, and fails naming the variable when one the run
  needs is missing. `e2e/shell.spec.ts` no longer calls `test.skip` for a missing variable.
- Tracing is off. Screenshots and video stay on failure.
- A bypass-header helper: when `E2E_BASE_URL` is set and `VERCEL_AUTOMATION_BYPASS_SECRET`
  is set, the header goes to the deployment's own origin only, from a route handler. It
  never goes through `extraHTTPHeaders`, so Clerk's domain never receives it.
- `.env.example` lists every name the suite reads, with no value.
- E2E tests for the `/try-out` criteria a user can see or do (01.05.01 criteria 1, 3, 7,
  8), and for the signed-out redirect from `/` to `/sign-in`. Signed-out and read-only
  tests carry `@smoke`.

## Out of scope

The CI workflow (01.05.05), the verification skill (01.05.06), any app code, a production
test account.

## Acceptance criteria

- [x] `npm run e2e` passes from a clean checkout of this branch with every test run and
      none skipped.
- [x] With `E2E_CLERK_TEST_EMAIL` unset, the run fails and the error names the variable.
- [x] No spec calls `test.skip` for a missing variable.
- [x] The bypass header reaches only the deployment's own origin (a test proves the
      handler adds it there and not on another origin).
- [x] Tracing is off in the config.
- [x] `.env.example` lists every name the suite reads, none with a value.
- [x] `/try-out` has a test for each of 01.05.01 criteria 1, 3, 7 and 8.
- [x] A signed-out visit to `/` ends on `/sign-in`, tested.
- [x] Only signed-out, read-only tests are tagged `@smoke`.
- [x] Lint, typecheck, unit tests and build pass.

## Demo / verification

Run `npm run e2e` locally and read the list: every test ran, none skipped. Unset
`E2E_CLERK_TEST_EMAIL` and run again: red, and it names the variable.

## Review budget / risk

Small: about 7 files, test code and config only. Risk: low for the app, medium for the
secret header, covered by a test.

## Decisions

### Where does a missing variable fail?

**Pick:** in the config for what the local build needs (`DATABASE_URL` and the two Clerk
keys), and in the test for what only a test needs (`E2E_CLERK_TEST_EMAIL`, the Clerk keys
for signing in).

**Rejected:** every check in the config. The config cannot tell which tests will run, and
the production run executes only `@smoke` tests with no test account and no Clerk keys, so
it would fail on every deploy.

**Evidence:** *inferred* from `ns-shared/e2e.md` (production runs `--grep @smoke`).
**Principle:** fail loudly, at the narrowest point that knows the need.
**Undo:** trivial, test files only.
**Decided by:** user, approved on the design card.
